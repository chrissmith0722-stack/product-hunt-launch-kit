# product-hunt-launch-kit

Checklist, tagline formulas, and hunter outreach copy for launching an indie tool or digital product on Product Hunt.

## Contents

- `CHECKLIST.md` — pre-launch → launch day → follow-up
- `TAGLINE_FORMULAS.md` — fill-in formulas for the short tagline
- `HUNTER_OUTREACH.md` — polite template to ask a hunter (or self-hunt notes)

## How to use

1. Work the checklist 2 weeks out.
2. Draft 5 taglines with the formulas; pick one and A/B the rest in drafts.
3. Send hunter outreach 5–7 days before launch (or schedule a self-hunt).

Not affiliated with Product Hunt.
